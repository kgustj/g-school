# g-school

2021년 G-school(C_lab) 과정에서 만든 웹 프로젝트 모음입니다. 원래 저장소 3개를 커밋 기록 그대로 폴더별로 합쳤습니다.

| 폴더 | 내용 | 기술 | 기간 | 커밋 |
|---|---|---|---|---|
| [`portfolio`](portfolio) | G-school 포트폴리오 "Root's History in G-school": M1~M3 개인 프로젝트, 주제중심 수업, 팀 프로젝트 발표 자료 | HTML, CSS | 2021.01~ | 8 |
| [`curtaincall`](curtaincall) | 연극 정보·커뮤니티 사이트 "커튼콜": 메인, 장르별 목록, 상세, 커뮤니티, 로그인 화면과 Express 서버 | HTML, CSS, JavaScript, Node.js, Express, Pug | 2021.05~ | 59 |
| [`infographic-chart`](infographic-chart) | "깨토리 인포그래픽": 버튼으로 항목을 바꿔 보는 차트 페이지 | HTML, CSS, JavaScript, Chart.js | 2021.07~ | 15 |


## 실행

- `portfolio`, `infographic-chart`: `index.html`을 브라우저로 열기
- `curtaincall`: 화면은 각 폴더(`Main`, `Genre1` 등)의 `index.html`을 열기. 서버는 `npm install` 후 `npm run dev`

## 관련 저장소

- [`create-curtaincall-node`](https://github.com/kgustj/create-curtaincall-node): `curtaincall`을 개인적으로 이어서 업데이트한 Node.js 버전

## 원래 저장소

`gschool-portfolio-js`, `gschool-curtaincall-js`, `gschool-infographic-chart`
